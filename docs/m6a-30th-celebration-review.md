한국판 공식 봉입률은 공개되지 않았다. FUR 발생률은 일본판 공개 집계의 근삿값을 잠정 차용하되, 박스 구성과 FUR/SAR 관계는 한국판 개봉 기록을 우선한다.

  잠정값을 박스 1/120(약 0.83%)·낱팩 1/2,400(약 0.042%)으로 둔다. 색상별 발생 표본은

- 박스 시뮬은 한국판 3박스 기록의 RR 5장·AR 4장·복각 2장과 SAR 또는 FUR 1장을 사용한다. 낱팩은 한국판 팩 단위 표본이 없어 기존 공개 조합표를 분포 형태의 보조 자료로만 사용하며, SAR 기대값은 FUR 대체율만큼 낮춘다.

- 상세 모달은 원본 이미지를 우선한다. 이전 개봉 기록에 저장된 104~165번의 `.gif` 주소도 현재 `.jpg` 주소로 해석하며, 교체된 5장의 256/512 캐시 버전도 갱신한다.

## 로딩·봉입 조합·시세 후속 감사 (2026-09-17)

### 이미지 및 렌더링

- 176장 × 256/512 WebP 총 352개 CDN 검증에서 누락·잘못된 규격·실패가 없었다. 로컬 variant 설정은 켜져 있고 박스/자판기 카드 타일은 256px, 상세 모달은 원본을 사용한다. 변환 누락은 이번 검사에서 재현되지 않았다.
- 접힌 갤러리의 카드 컴포넌트 생성을 펼칠 때로 미룬다. 전체 카드 목록은 100장씩, 박스별 기록은 5박스씩 추가 표시해 한 번에 생성하는 이미지/효과 레이어를 제한한다. 기록 자체를 삭제하거나 집계를 줄이지 않는다.
- 박스/자판기 타일의 반짝임은 이미지 로딩 완료 후 시작한다. 여러 히트가 있는 팩은 마지막 카드뿐 아니라 각 카드의 레어도·가격을 기준으로 효과를 적용한다.
- 누적 운 분포가 부동소수점 오차로 동일 점수를 서로 다른 상태로 취급하던 문제를 수정했다. 기존 허용 오차 `1e-9`로 병합하고, 합성 중 중간 배열 대신 Map으로 누적한다. 20박스 계산은 같은 환경에서 변경 전 약 1,626ms/75,551상태, 합성 최적화 후 약 69ms/8,621상태였다. 봉입 조합 수정까지 반영한 최종 측정은 약 51ms/8,369상태다. 환경별 실행 시간은 달라질 수 있다.
- `profile-m6a-runtime.ts 20`은 성능 수치뿐 아니라 확률 합 1, 평균·분산의 합성 전후 일치, 근접 중복 상태 부재를 검사한다. 실제 브라우저의 응답 없음 현상은 사용 가능한 브라우저 연결이 없어 직접 재현하지 못했다. 위 항목을 유일한 원인 또는 완전 해결로 단정하지 않는다.

### 봉입 조합의 정밀 검토

- `CELEBRATION_30_BOX_COUNTS`는 한국판 3박스 기록의 RR 5·AR 4·복각 2 고정 행을 보존한다. 고레어 슬롯은 SAR 또는 FUR 한 장으로 추첨한다.
- 낱팩은 공개된 340팩 조합표를 형태의 보조 자료로만 사용한다. 한국판 박스 기대값(RR 5·AR 4·복각 2)을 맞추고 SAR 가중치는 FUR 대체율만큼 낮춘 모델 조정이며, 한국판 팩 단위 실측이 아니다.
- 박스는 9개 히트 팩으로 배치한다. 박스별 장수 제약을 우선하므로 박스 내 조합 빈도와 낱팩 구성표의 빈도가 완전히 동일하다는 주장은 하지 않는다.
- RGB와 다른 히트의 동봉 관계, 색상별 빈도, 한국판 수록 여부는 여전히 미확인이다. 독립 추가와 3색 균등은 가정으로 남긴다. 각 레어도 안의 카드 선택도 균등 가정이며, 적은 카드별 관측 건수만으로 개별 SAR 확률을 다르게 만들지 않는다.
- 최종 회귀검사: 20,000박스·40,000낱팩에서 각 등급 빈도가 설정값 5σ 범위 안인지, 176종 전체 도달, 피카츄·에너지 각 1장, SAR 또는 FUR 보장, FUR/SAR 상호 배타, AR·복각 박스 내 중복 회피, 조합표/박스 행 일치와 JSON 동기화를 검사한다. **시뮬 검사 건수는 실제 봉입 근거가 아니다.**
