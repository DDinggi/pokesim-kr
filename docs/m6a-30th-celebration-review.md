## 잠정 봉입 모델

한국판 공식 봉입률은 공개되지 않았다. 일본판 공개 집계를 잠정 준용한다.

- 초기 tcgTalk 57박스: SAR 57장(박스당 1장), FUR 14장(14/57박스). FUR 수치는 아래 9월 17일 재검토에서 갱신했다.
- FUR가 나온 14박스에도 SAR가 각각 1장씩 있었으므로, 현재 시뮬처럼 FUR는 SAR를 대체하지 않는 추가 슬롯으로 둔다. 단일 공개 표본에 근거한 일본판 추정이지 공식 보장은 아니다.
- 그중 상세 기록 17박스: RR 77장(박스당 3~5장), AR 63장(3~5장), 복각 35장(2~3장).
- 17박스 중 15박스는 히트 팩 9개, FUR가 나온 2박스는 히트 팩 10개로 기록됐다.
- 별도 일본판 120박스(2,400팩) 단일 개봉에서 RGB 뮤 빨강 1장이 관측됐다. RGB 전체의
  잠정값을 박스 1/120(약 0.83%)·낱팩 1/2,400(약 0.042%)으로 둔다. 색상별 발생 표본은
  없어 RGB 발생 시 3종 균등 추정한다. 1건뿐인 표본이라 오차가 매우 클 수 있다.
- 박스 시뮬은 17박스의 RR·AR·복각 장수 행을 함께 추첨한다. 낱팩은 340팩의 공개 조합표를

## 봉입률 재검토·표시 개선 (2026-09-17)

- PokéGet의 [9월 16일 조사](https://pokemon-infomation.com/pull-rates-30th/)는 약 720박스/60카톤을 근거로 FUR 약 6박스당 1장, SAR 1장, RR 5장, AR 4장, 복각 2장을 제시한다. FUR는 더 큰 조사 기준의 공개 근삿값 `1/6`(약 16.67%)으로 갱신한다. **실제 FUR 관측 건수는 미공개**이므로 `120/720` 실측이라고 기재하지 않는다. 문서 서두의 1,000박스와 9월 13일 사전 안내는 현재 조사수 표와 달라 표본으로 사용하지 않는다.
- RR·AR·복각은 위 자료에 변동 빈도표가 없고 장수가 전후할 수 있다고 명시되어 있다. 따라서 기존 17박스의 실제 빈도표(3~5·3~5·2~3)를 유지한다. SAR 1장과 FUR+SAR 동시 봉입은 tcgTalk의 박스별 기록과도 일치한다.
- RGB는 PokéGet 본문에서 건수와 분모를 함께 확인할 수 없어 기존 120박스 중 1장 관측을 잠정 유지한다. 색상별 균등과 한국판 차용의 불확실성도 유지한다. 같은 개봉 자료를 재인용한 글들을 서로 독립적인 표본으로 합산하지 않는다.
- 상세 모달은 원본 이미지를 우선한다. 이전 개봉 기록에 저장된 104~165번의 `.gif` 주소도 현재 `.jpg` 주소로 해석하며, 교체된 5장의 256/512 캐시 버전도 갱신한다.
- 이번 박스 결과에 피카츄 01~30별 획득 수량을 접어서 볼 수 있는 영역을 추가하고, 도감에는 `전체 / 획득 / 미획득` 필터를 제공한다. 누적 기록과 이번 박스 수량은 각각 구분한다.

검증: `pnpm --dir scripts exec tsx audit-m6a-review.ts`의 고정 시드 20,000박스에서 FUR 3,427박스(17.135%), RGB 174박스(0.870%)로 설정 확률의 표본 오차 범위 안이었다. 전 팩 피카츄·에너지 1장, 전 박스 SAR 1장, 피카츄 30종 도달, 예전 이미지 주소 62개의 최신 원본 연결 및 원본/공개 JSON 일치를 검사했다. **이 수치는 코드 회귀검사이며 실제 봉입률의 근거 표본이 아니다.** 별도 1,000박스 보장 검사와 CDN WebP 352개 검사도 오류 없이 통과했다.

## 로딩·봉입 조합·시세 후속 감사 (2026-09-17)

### 이미지 및 렌더링

- 176장 × 256/512 WebP 총 352개 CDN 검증에서 누락·잘못된 규격·실패가 없었다. 로컬 variant 설정은 켜져 있고 박스/자판기 카드 타일은 256px, 상세 모달은 원본을 사용한다. 변환 누락은 이번 검사에서 재현되지 않았다.
- 접힌 갤러리의 카드 컴포넌트 생성을 펼칠 때로 미룬다. 전체 카드 목록은 100장씩, 박스별 기록은 5박스씩 추가 표시해 한 번에 생성하는 이미지/효과 레이어를 제한한다. 기록 자체를 삭제하거나 집계를 줄이지 않는다.
- 박스/자판기 타일의 반짝임은 이미지 로딩 완료 후 시작한다. 여러 히트가 있는 팩은 마지막 카드뿐 아니라 각 카드의 레어도·가격을 기준으로 효과를 적용한다.
- 누적 운 분포가 부동소수점 오차로 동일 점수를 서로 다른 상태로 취급하던 문제를 수정했다. 기존 허용 오차 `1e-9`로 병합하고, 합성 중 중간 배열 대신 Map으로 누적한다. 20박스 계산은 같은 환경에서 변경 전 약 1,626ms/75,551상태, 합성 최적화 후 약 69ms/8,621상태였다. 봉입 조합 수정까지 반영한 최종 측정은 약 51ms/8,369상태다. 환경별 실행 시간은 달라질 수 있다.
- `profile-m6a-runtime.ts 20`은 성능 수치뿐 아니라 확률 합 1, 평균·분산의 합성 전후 일치, 근접 중복 상태 부재를 검사한다. 실제 브라우저의 응답 없음 현상은 사용 가능한 브라우저 연결이 없어 직접 재현하지 못했다. 위 항목을 유일한 원인 또는 완전 해결로 단정하지 않는다.

### 봉입 조합의 정밀 검토

- 이전 RR·AR·복각 독립 추첨은 관측되지 않은 장수 조합도 만들었다. `CELEBRATION_30_BOX_COUNTS`에 원문 17개 행을 보존해 공분산까지 반영한다. SAR는 박스당 1장이고 FUR는 여전히 추가 슬롯이다.
- 낱팩은 원문 340팩 구성표를 사용한다. 독립 베르누이 추첨으로 3~4개 히트가 겹치거나 한도를 넘긴 카드를 잘라내던 경로를 없앴다. FUR-only 5팩과 FUR+복각 1팩 가중치에 `(1/120)/(6/340)`을 곱하고, 줄어든 질량을 각각 무히트·복각-only로 이동한다. 이는 새 FUR 추정치에 맞춘 **모델 조정**이지 새로운 실측 표본이 아니다. RR·AR·복각·SAR 기대 장수는 그대로 보존된다.
- 박스는 9개 히트 팩, FUR 박스 중 1/3은 10개 히트 팩이라는 소표본 구조를 사용한다. 관측된 두 장 조합의 상대 가중치로 팩을 구성하되 박스별 장수 제약을 우선한다. 따라서 박스 내 조합 빈도와 낱팩 구성표의 빈도가 완전히 동일하다는 주장은 하지 않는다. 미관측 조합이 실물에 절대 없다는 뜻도 아니다.
- RGB와 다른 히트의 동봉 관계, 색상별 빈도, 한국판 수록 여부는 여전히 미확인이다. 독립 추가와 3색 균등은 가정으로 남긴다. 각 레어도 안의 카드 선택도 균등 가정이며, 적은 카드별 관측 건수만으로 개별 SAR 확률을 다르게 만들지 않는다.
- 최종 회귀검사: 20,000박스 FUR 3,389(16.945%), RGB 178(0.890%). 추가 40,000낱팩의 각 등급 빈도는 설정값 5σ 범위 안이었다. 176종 전체 도달, 피카츄·에너지 각 1장, SAR 보장, AR·복각 박스 내 중복 회피, 조합표/박스 행 일치와 JSON 동기화를 검사했다. **시뮬 검사 건수는 실제 봉입 근거가 아니다.**

### 시세와 반짝임

- FullAhead M6a 168개 상품에서 고레어 65장(AR 20·SAR 10·FUR 2·복각 30·RGB 3)의 판매 참고가를 갱신했다. 기존 수집기가 숫자 번호만 읽어 놓치던 `R/RGB`, `G/RGB`, `B/RGB`를 실물 번호로 매칭한다. 내부 정렬 번호 166~168로 추측 매칭하지 않는다.
- RGB 상세 페이지의 현재 표시가와 `product:price:amount`를 직접 교차 확인했다: [빨강 698,000엔](https://pokemon-card-fullahead.com/shopdetail/000000061911/), [초록 448,000엔](https://pokemon-card-fullahead.com/shopdetail/000000061912/), [파랑 548,000엔](https://pokemon-card-fullahead.com/shopdetail/000000061913/). 검색 캐시는 빨강 798,000엔을 보여 최신 수집의 근거로 사용하지 않았다. 상품 설명 일부의 복사 오류는 카드 이름·이미지 메타로 수입하지 않았다.
- 수집 가격은 일본 판매처의 표시가이며 거래 체결가가 아니다. 기존 프로젝트 설정 `JPY/KRW=9.5`, `jp_to_kr_factor=0.65`를 적용한 한국 참고 추정가를 저장한다. 환율·보정계수를 새 실측처럼 취급하지 않는다. 수집일·출처·JPY 원가를 카드별로 보존한다.
- 기존 반짝임 기준 10만/30만/80만원은 유지한다. 현재 뮤 ex FUR(109,900원)·복각 루기아(103,700원)는 value, RGB 3종은 jackpot 기준에 해당한다. 저가 AR/복각 전체를 일괄 고가 효과로 올리지 않는다. 시세 변경 후 운 분포 20,000박스/40,000팩도 다시 생성했다.
