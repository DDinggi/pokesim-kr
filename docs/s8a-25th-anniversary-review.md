# 25th ANNIVERSARY COLLECTION 검토

검토일: 2026-10-26. 카드 메타·참고가 원장은
[s8a-25th-anniversary-review.json](../data/manual/s8a-25th-anniversary-review.json)에 보존한다.
한국판 공식 봉입률은 비공개이며 아래 빈도는 일본판 자료를 차용한 근사다.

## 누락과 상품 구성

기존 57종은 본팩 32종과 S8a-P 프로모 25종이었다. 본팩 25~30번이 누락되어
피카츄 V-UNION 네 조각, 박사의 연구 SR, 뮤 UR이 나오지 않았고,
검증 코드가 이 여섯 번호를 누락 허용 목록으로 처리하고 있었다. 해당 예외를 제거했다.

- [한국 공식 본팩 상품](https://pokemoncard.co.kr/card/387): 16팩×5장, 총 80장.
- [한국 공식 스페셜 세트](https://pokemoncard.co.kr/card/386): 본팩 4팩과 별도 프로모 1팩.
- [한국 공식 피카츄 V-UNION](https://pokemoncard.co.kr/cards/detail/BS2021015025):
  25~28번 RRR 네 조각. 합본을 공식 번호 순서인 좌상·우상·좌하·우하로 분할했다.
- [일본판 전체 목록](https://www.pokeguardian.com/sets/set-lists/japanese-sets/753007_s8a-25th-anniversary-collection):
  한국 공식 상세가 확보되지 않은 29번 박사의 연구 SR·30번 뮤 UR을 D-148/D-152에 따라 보강했다.
  한국 이름은 기존 한국 공식 일반 카드로 대응하고, 일본판 이미지와 출처를 표시한다.

서비스의 박스 개봉은 **본팩 16팩 + 별도 구매특전 프로모 4팩** 조합이다.
본팩 자체가 항상 프로모를 내장한다는 뜻이 아니며 실제 점포의 특전 재고·지급 조건을 재현하지 않는다.
`box_size=16`, `pack_size=5`, `bonus_pack_count=4`로 저장한다. 결과 배열에는 본팩 16개 뒤에
`is_bonus=true`인 1장짜리 프로모팩 4개가 붙는다. 따라서 본팩은 항상 80장이고 조합 전체는 84장이다.
낱팩 개봉은 본팩 5장만 반환한다. 예전의 낱팩 25% 프로모 추가와 6장짜리 본팩은 폐기했다.

## 봉입 빈도 근거

주 원자료는 [しゃあく의 일본판 52팩 개봉 표](https://shark-tcg.com/s8a-kaihu/)다.
공개된 표에서 RR 13장, VMAX 5장, V-UNION 각 조각 4장씩(완성 세트 4개), SR 3장,
UR 0장, 기본 에너지 52장을 확인했다. 팩별·박스별 원래 배열이나 재판 여부는 확인되지 않는다.
개인 한 명의 작은 표본이라 한국판 확정 빈도 또는 커뮤니티 전체 합의로 표현하지 않는다.

| 팩 사건 | 사용하는 낱팩 확률 | 근거와 한계 |
| --- | --- | --- |
| RR 1장 | 13/52 | 위 원자료의 팩당 등장 장수 근사 |
| VMAX 1장 | 5/52 | 위 원자료의 두 VMAX 합계. 개별 두 카드는 균등 선택 |
| V-UNION 4장 동시 | 4/52 | 네 조각을 한 사건으로 묶고 에너지 1장을 더한 5장 팩 |
| SR 또는 UR | 1/16 | 일본판의 약 한 고레어/박스 공개 추정을 차용 |
| UR | 1/(20×16) | 일본 공개 추정 약 20박스당 1장. 실제 집계 표본 수는 `null` |
| 별도 프로모 | 낱팩 0, 조합 박스 4팩 | 본팩과 구별되는 구매특전 구성 |

고레어·UR의 보조 근거는 [일본 공개 봉입 추정표](https://premium.gamepedia.jp/pokeca/archives/17377)다.
52팩에서 UR이 없었다고 UR 확률을 0으로 만들지 않는다. 해당 공개 추정의 정확한 관측 건수·분모는
확인되지 않아 52를 UR 표본으로 전용하지 않는다. SR과 UR이 같은 박스에 동봉되는 비율도 확인되지 않았다.
따라서 **고레어 한 슬롯 안에서 SR 95%·UR 5%로 대체**하는 잠정 가정이며 추가 UR 슬롯은 만들지 않는다.
이는 공식 보장이나 검증된 SR·UR 동봉 구조가 아니다.

[일본 프로모 조사 사이트](https://pokemon-infomation.com/market-price-25thpromo/)의 각 1/25 추정을
프로모 25종의 균등 선택에 차용한다. 공식·한국 실측 수치가 아니며 확인된 표본 수는 `null`이다.

## 시뮬과 운 모델

박스에서는 SR/UR 한 팩을 예약하고 위치를 섞는다. 나머지 15팩은 위 낱팩 사건에서 고레어를 제외한
조건부 가중치를 사용한다. 이 방식으로 본팩 16개 전체의 RR·VMAX·V-UNION 기대값이 낱팩 모델과 일치한다.
일반 팩 사건은 카드 한 장과 기본 카드 세 장, 기본 에너지 한 장으로 구성한다.
일반 사건에는 기본 카드 네 장과 에너지 한 장이 들어간다. V-UNION 팩에는 정해진 네 조각이 함께 나온다.
같은 RRR이라도 V-UNION 조각을 VMAX의 한 장 풀에 섞지 않는다.

박스당 기대값은 RR 4장, VMAX 20/13장, V-UNION 16/13세트다. V-UNION 사건 수와
RRR 조각 수를 혼동하지 않으며, 운 분포는 V-UNION 사건에 RRR 네 장의 점수를 부여한다.
별도 프로모 네 장은 박스의 고정 기대값이고 낱팩의 기대값에는 포함되지 않는다.
SR은 기존 25주년 점수 체계에서 0점, UR은 기존 공통 최상위 3점을 적용한다.
본팩의 기본 홀로·미러 인쇄 차이는 별도 카드나 추가 시세로 모델링하지 않는다.

## 이미지와 참고가

본팩 V-UNION은 한국 공식 PNG의 2×2 분할이며 한 조각의 실제 원본 크기는 248×345다.
이를 고해상도 원본으로 주장하지 않는다. 두 시크릿과 프로모는 일본판 이미지 보강이다.
신규 여섯 장과 프로모25종의 원본·256/512 WebP를 버전된 R2 키에 업로드했다.
프로모의 기존512 경로는 실제500px여서 새 키로 규격을 맞췄고, 이전 기록 주소도 매핑했다.
전체63개 카드의256/512 WebP126개 규격·존재 검사를 통과했다.

참고가는 FullAhead의 일본 판매 호가를 기존 프로젝트 설정(JPY/KRW 9.5, 한국 보정계수 0.65)으로
환산한 값이다. 한국 RAW 실거래가가 아니며 환율 설정일(2026-06-07)도 원장에 보존한다.
프로모는 별도 S8a-P 카테고리로 대응하고, 일반 카드에 더 비싼 미러 가격을 붙이지 않는다.
한국 공중날기·파도타기 피카츄의 21~24번은 일본판 23·24·21·22번에 대응한다.
V-UNION은 4장 세트 가격을 네 조각에 나누어 합계를 보존한다. 같은 세트 가격을 네 번 더하지 않는다.

## 검증

```powershell
pnpm --dir scripts exec tsx validate-anniversary-25.ts
pnpm --dir scripts validate:data -- --set s8a-25th-anniversary --strict
pnpm --dir scripts validate:luck -- --set s8a-25th-anniversary --strict
pnpm --dir scripts validate:box-guarantees -- --set s8a-25th-anniversary --trials 1000
pnpm --dir scripts build:luck-dist -- --set s8a-25th-anniversary
```

전용 검사는 5,000박스·40,000낱팩에서 모든 본팩 카드 도달성, 프로모 분리,
V-UNION 네 조각 동시 등장, 단일 SR/UR 슬롯, 운 기대값·점수 분포 일치를 확인한다.
시뮬 검사 표본을 실제 봉입률의 관측 표본으로 사용하지 않는다.

2026-10-26에 최종 가격을 반영해 가치 운 분포를 재생성했다. 공식 정체성 대조의 한국36개 항목은
합본4조각까지 확인했고, 일본 보강27개 항목은 한국 공식ID 부재로 미검증 표시를 유지했다.

  주장하지 않는다. 한국의 한 팩 내 네 조각 동봉 여부는 여전히 미확인이며,

자판기에는 일반 낱팩(5장, 프로모 없음)과 스페셜 세트(4+1, 총21장)를 별도로 표시한다.
스페셜은 파생 상품 코드 `s8a-25th-anniversary-special`로 상품 단위 기록을 보존하고,

글로벌 실제 구성 팩 수는 본팩4개로 보고 프로모는 유료 팩 수에서 제외한다.
힛카드도감은 원본 25주년 하나로 유지하며 계정 보관·복원에도 파생 상품 메타를 공급한다.

전용 참고가 운 분포는 다음 명령으로 20,000상품을 계산해
`data/products`와 `frontend/public/products`에 저장한다. 기반 시세는 기존 일본 참고가이며
한국 실거래 시세나 실제 봉입 관측 표본이 아니다.

pnpm --dir scripts build:luck-dist -- --set s8a-25th-anniversary-special
