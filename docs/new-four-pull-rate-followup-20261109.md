# 신규 4종 봉입률 추가 조사 (2026-11-09)

**한국판 실물 완박스 10개를 대조한 결과 XY7·XY8의 현행 보장 장수와 맞지 않았다. 현재 수치를 실제 한국판과 유사하다고 승인할 수 없다.** 포켓심쿵은 일본판 5박스를 추가해 총 15박스로 늘렸고 RR 4~6장 범위는 유지됐지만, 장수별 확률까지 검증된 것은 아니다.

이번에는 조사 원장을 보강했다. 런타임 확률·운 분포·배포 상태는 변경하지 않았다. 기존 구현 회귀 테스트 통과와 실물 봉입률 검증을 구분한다.

## 조사 기준

- 박스 개봉/전체 팩을 꺼내는 장면, 실제 히트 노출, 마지막 정리를 대조했다. 제목의 ‘2개’, ‘7탄’을 RR 수나 박스 수로 읽지 않았다.
- 같은 박스의 1·2부는 합치고 재업로드·혼합 상품·팩 수 미대조 영상은 합계에서 제외했다. 배경에 전시한 기존 카드도 새 획득에서 제외했다.
- 한국 XY 30팩×5장과 일본 XY 20팩×5장은 별도 집계했다. 포켓심쿵은 양쪽 20팩이나 한국 5장/일본 4장이다.
- 공개 개봉은 무작위 표본이 아니며 업로드/검색 편향이 있다. 생산 로트·초판/재판 구분도 미확인이다. 아래 숫자는 관측 원장의 기술통계이며 제조 확률이 아니다.
- 히트 중심의 프레임 대조다. 모든 일반 카드의 번호를 전수 전사한 것은 아니다. 재검증 가능한 URL·타임스탬프·카드 목록을 JSON에 보존했다.

## 일본판 밴디트링: 누적 18박스 집계 확보

[2015-06-21 누적 18박스 원문](https://raimublog.seesaa.net/article/421065563.html)은 RR 54장·SR 8장·UR 10장을 열거한다. [전날의 8박스](https://raimublog.seesaa.net/article/421014384.html)를 포함한다고 명시하므로 8+18=26박스로 세지 않는다. 박스별 조합은 없어 고레어 동시 봉입 분포를 복원할 수 없다.

[다른 작성자의 2박스](https://perappu-johokyoku.blog.jp/archives/968302.html)는 각각 RR 3장+UR 1장이다. 글의 SR/UR 필수 문장은 취소선 처리 후 미봉입 박스가 있다는 설명으로 정정돼 있다. 두 자료의 일본판 20박스 합계는 RR 60·SR 8·UR 12이지만 한국 수치와 합치거나 고레어 보장으로 사용하지 않는다.

[또 다른 5박스 글](https://ameblo.jp/vulakey/entry-12041811155.html)은 텍스트 목록이 RR 14·SR 2·UR 2, 총 18장이다. ‘EX 4장 확정’이라는 작성자 문장과 합계가 맞지 않아 사진별 대조 전 정량 합계에서 제외했다.

합계 **RR 72장/300팩**, 장수 분포는 **4장 5박스·5장 8박스·6장 2박스**다. 관측 평균 4.8장/박스·24%/팩이다. 기존 모델은 최초 10박스에 맞춘 4.7장·23.5%이며 이번 조사로 자동 변경하지 않았다. RR 4~6장의 존재 근거는 강화됐지만 한국 장수별 비율·카드별 균등 가정은 미확정이다.

[TV악어](https://www.youtube.com/watch?v=sDwNysjh9D8)는 기존 한국 마스터 영상을 화면 녹화한 재업로드여서 제외했다. [두 사람이 함께 개봉하는 영상](https://www.youtube.com/watch?v=5CmFMClGe5s)은 박스와 별도 상품의 카드 귀속을 완전히 분리하지 못해 제외했다.

## 반영 판단

1. XY7·XY8의 일본→한국 팩 수 비례 환산과 고정 보장 장수는 재설계 대상이다. 특히 XY8 일반 EX 3장·RR 6장 고정은 한국 영상과 맞지 않는다.
2. 소표본의 최솟값/최댓값을 제조 보장으로 바꾸거나 미관측 UR을 0으로 만들지 않는다. SR/UR 상대 가중치·동시 봉입·일반 R 장수도 별도로 검토해야 한다.
3. 포켓심쿵은 RR 4~6장 범위가 추가 근거와 맞는다. 정확한 장수별 비율·카드별 빈도·C/U 균형 배분까지 실물과 같다고 표현하지 않는다.
4. 확률 변경 시 박스·낱팩/자판기·등장 운·가치 운 분포를 같은 작업으로 재생성하고 검사한다. 이번에는 조사 자료만 갱신했다.
