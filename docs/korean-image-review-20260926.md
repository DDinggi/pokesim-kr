PNG 원본은 R2에 보존하지만 현재 공개 CDN에서는 차단되므로 서비스 준비의 성공 기준으로 세지 않는다.

## 정체성·기록·시세

- 기존 `card_num`은 사용자 획득 기록 호환을 위해 유지한다. 한국 공식 ID는 `_official_card_num`,
  한국 인쇄 번호는 `number`, 다른 일본 번호는 `_jp_number`로 구분한다.
- 스톰에메랄다 피아나의 신뢰는 JP 102 → KR 103, 풍&란의 수행은 JP 103 → KR 102.
  098·099 이름은 공식 `포켓몬 캐처`·`특별주문조끼`로 교정한다.
  공식 상세를 새로 조회하며 누락된 포켓몬 24장의 HP·타입도 채웠다.
- 백은의 랜스 한국 080~083의 멜론·민지·의사·피오니는 JP 083·080·081·082에 대응한다.
  잘못 붙은 일본 이미지와 가격을 함께 교정하고 `price-matches.json`에 번호 대응을 기록했다.
  가격은 기존 출처 스냅샷의 재매칭이며 최신 시세를 새로 수집한 것은 아니다.
- V-UNION 056~059는 좌상·우상·좌하·우하로 분할하며 합본을 한 카드로 표시하지 않는다.
- 예전 개봉 결과의 이미지 주소도 `frontend/lib/card-image-replacements.json`을 통해 한국판으로 연결한다.
- 변경 전후 카드·근거·원본 크기는 `data/manual/korean-image-review-20260926.json`에 보존한다.

## 검증

`pnpm --dir scripts validate:korean-images -- --cdn`은 93개 메타/기록 주소 대응,
원본 출처와 CDN 무손실 상세의 디코딩 픽셀 해시/크기, 256/512 형식·너비·픽셀 유사도를 검사하고
`.tmp`에 검수 시트를 만든다. 파일 바이트가 다른 PNG/WebP는 디코딩 픽셀로 비교한다.
네 세트마다 동일 시드 1,000박스·10,000팩의 변경 전후 등급별 장수를 비교하고 교체 카드 도달성을 검사한다.

기존 `validate:box-guarantees`에서 백은의 랜스는 SR 표기가 HR/UR 대체 슬롯과 맞지 않고,
VMAX 클라이맥스는 특수팩이 일반 장수 범위를 초과해 실패한다. 이 검사는 전부 통과했다고 보고하지 않는다.
이번 이미지 작업 전후 동일 시드의 등급별 장수는 일치하며 봉입률 모델은 변경하지 않았다.
스톰에메랄다는 기존 시세 데이터가 없어 가치 운 대신 등급 기반 폴백을 유지한다.
공식 상세 90장은 이름·번호·레어도·HP·타입 재대조 대상이다. V-UNION 057~059는 독립 상세가
없어 자동 검증에서 미검증 3개로 남기고, 공식 056 합본에 인쇄된 각 번호를 직접 확인한다.

푸시·PR·운영 앱 배포는 별도 요청 시 진행한다. R2 자산 준비와 앱 배포 완료는 구분한다.
